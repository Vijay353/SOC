## Top production gaps

1. No real authentication/authorization (demo identity header).
2. Vendor adapters are placeholders; Graph has no ETag, so production staleness checks rely on timestamps.
3. Single process, SQLite, no durable background worker for outbox retries — retries happen only when a user re-clicks.
4. Packet status reaches the Gate only by polling on view/decision.
5. Audit is tamper-evident locally but not shipped to immutable external storage.
6. Rules extractor covers fixture phrasing only; real runbooks need the model path plus evaluation data.
7. No user research has validated the 30-second comprehension claim or the decision thresholds.
